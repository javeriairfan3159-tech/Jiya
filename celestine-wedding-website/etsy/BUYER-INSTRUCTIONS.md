## Edit in 5 minutes

1. Click any text — names, date, venue.
2. Click any photo → Replace.
3. Hotel and registry buttons: highlight text → link icon → paste your URL.
4. RSVP: connect Canva Forms, or link the button to Google Forms / Zola / The Knot.

## Suggested RSVP questions (Google Form)

- Full name
- Email
- Will you attend? (Yes / No)
- Number of guests
- Meal (Garden herb / Orchard vegetable / Child)
- Allergies
- Song request
