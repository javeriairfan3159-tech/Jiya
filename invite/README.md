## Print

1. Open a variation HTML file in Chrome.
2. Print → Paper size **5 × 7 in** (or custom 5×7).
3. Margins: **None**, scale: **100%**.
4. Or Save as PDF at 100% for a print shop.

Artwork uses original stylized toy illustrations (theme-inspired), not franchise character art.
