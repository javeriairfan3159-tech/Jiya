# Etsy listing kit — Jiya Travel Planner

Competitor-style mockups for a **travel planner mobile web app** listing (photos + short video + SEO copy).

## Upload to Etsy

1. Open `ETSY-LISTING.md` and paste the title, tags, and description.
2. Upload `images/01-hero.jpg` as photo 1, then `02`–`10`.
3. Upload `video/listing-video.mp4` as the listing video.

## Rebuild mockups

```bash
cd etsy-listing
./render.sh
```

Needs Chrome + ffmpeg. Destination photos live in `assets/`.
