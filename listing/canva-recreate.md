# Rebuild this suite in Canva

Use this if you want an editable Canva listing. Recreate the layout on a 5×7 in canvas, then duplicate for the other sizes. Do not screenshot a competitor template.

## Layout recipe (5×7)

1. Full-bleed pink cow-print rectangle (black spots on `#F4A7C0`).
2. Cream rounded rectangle inset ~0.24 in, corner radius ~0.2 in.
3. Double gold frame: 3 px gold, 9 px cream gap, 2 px pale gold.
4. Centered stack:
   - `SADDLE UP · SIP UP` — Cinzel, 11 pt, berry, tracking 400+
   - `MOO MOOS` — Rye, 72–80 pt, ink
   - gold rules + script `&`
   - `Margaritas` — Pinyon Script, 90 pt, hot pink
   - hero illustration (hat + cow-print margarita + disco ball)
   - `TO CELEBRATE` — Cinzel small caps
   - Name — Pinyon Script, 56 pt
   - Hot-pink ticket bar with circular notches: `30TH BIRTHDAY`
   - Three columns: DATE / TIME / PLACE with gold diamond gutters
   - Footer: `BOOTS ON · HATS OFF · CHEERS UP`

## Elements to keep original

- Pink cowhide outer (not a black-and-white cow-print picture frame)
- Ticket-stub age badge (not a scalloped ribbon banner)
- Cow-print fill *inside* the margarita
- Disco ball + hat cluster instead of a lone watercolor glass
- No copied corner-boot + cactus pair from another listing

## Upload path for a Canva product

1. Build the 5×7 as the master.
2. Duplicate pages for details, welcome, tag, and phone.
3. Mark every name/date/address text box as editable.
4. Export a PDF with a Canva template link for the Etsy download.
