# Velvet Garden — luxury birthday invitation suite

Print-ready **5×7** birthday invitations designed to outclass generic dusty-pink watercolor Etsy templates.

Three original colorways. Painterly peonies and gold-leaf botanicals. Editorial type. Asymmetric layouts — not clipart roses in every corner.

Demo guest of honour: **Amara** · Saturday 24 August · seven o’clock · The Conservatory, Villa Céleste.

## Print

- `print-png/` — 5×7 at **600 DPI** (3000×4200)
- `print-jpg/` — 5×7 at **300 DPI** (1500×2100)
- `exports/*.pdf` — 5×7, no margins
- `exports/*.png` — working renders (~384 DPI)

Print at 100% on 110–130 lb / 300 gsm cardstock. Trim to 5×7.

To re-render:

```bash
./render.sh
python3 make_listing.py
```

## Listing media

`listing/` — Etsy thumbnail, lifestyle mockup, square card photos, and `LISTING.txt` (title, tags, description, price).

Thumbnail order is documented in `listing/LISTING.txt`.
