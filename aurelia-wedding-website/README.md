# Aurelia — Canva Wedding Website Template

Olive, ivory, and terracotta wedding website for Etsy. Six Canva-editable pages, RSVP, and listing copy ready to paste.

Placeholder couple: **Elena & Matteo** · 18 October 2026 · Villa Oliveto, Tuscany

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home / welcome |
| `story.html` | Our story |
| `details.html` | Wedding day schedule, dress code, dinner |
| `travel.html` | Travel, shuttle, hotel blocks |
| `rsvp.html` | RSVP form |
| `info.html` | Wedding party, gallery, registry, FAQ |

## Open the local preview

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8765
```

Then visit http://localhost:8765
