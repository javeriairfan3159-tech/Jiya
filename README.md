# All-in-One Notion Life Planner

A ready-to-customize digital planner package designed for sale on Etsy. The
product uses a warm, minimal beige aesthetic and includes importable Markdown
pages, CSV databases, a customer setup guide, and ready-to-edit Etsy listing
copy.

## Package contents

- `notion-planner/` — dashboard, setup instructions, and eight CSV databases
- `seller-kit/` — Etsy listing copy, customer delivery guide, and license

## Quick start

1. Open `notion-planner/START-HERE.md`.
2. Import `notion-planner/DASHBOARD.md` into Notion.
3. Import each file in `notion-planner/databases/` as a separate CSV.
4. Follow `notion-planner/SETUP-GUIDE.md` to add views, relations, and formulas.

CSV import intentionally uses portable text, number, and date fields. Notion
does not preserve relations, formulas, templates, or custom views through CSV,
so the setup guide documents those finishing steps.
