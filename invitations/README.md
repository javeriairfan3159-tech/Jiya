# Winter Princess 3rd Birthday Invitation — 5x7

Original luxury winter-wonderland invitations designed to outshine typical Frozen-style competitor listings. Characters, copy, and layout are original (ice princess + snow creatures — not Disney IP), so the listing is more unique and safer to sell.

Print size: **5 x 7 inches**  
Print files: **3000 x 4200 px** (600 DPI PNG)
